# Lalit Enterprises — GitHub Pages Website

A static website for Lalit Enterprises, Jalgaon.

## Run locally
Simply open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `lalit-enterprises`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the Pages URL.

## Adding the supplied photographs
Replace the placeholder sample cards in `index.html` with `<img>` elements pointing to files in `assets/`.
Recommended folders:
- `assets/factory/`
- `assets/samples/`
- `assets/kiran-rane.jpg`

The current site intentionally works without external libraries or a build process.
